# نصب سریع

1. پروژه را در Android Studio باز کن.
2. Gradle Sync را انجام بده.
3. گوشی را با USB debugging وصل کن.
4. Run را بزن و Masten را نصب کن.
5. از Settings، Notification Access را برای Masten فعال کن.
6. اجازه Microphone و Notification را بده.
7. اگر AI محلی می‌خواهی، Backend را روی کامپیوتر/سرور اجرا و Ollama را فعال کن.
