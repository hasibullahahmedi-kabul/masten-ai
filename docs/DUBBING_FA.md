# دوبله فیلم/سریال — راهنمای راه‌اندازی

این قابلیت روی **Backend (کامپیوتر)** اجرا می‌شود، نه روی گوشی — چون STT، ترجمه و TTS برای یک فیلم کامل به CPU/RAM قابل توجهی نیاز دارند.
اپ اندروید فقط ویدیو را آپلود می‌کند، وضعیت پردازش را نشان می‌دهد، و در پایان فایل دوبله‌شده را دانلود می‌کند.

## ۱. نصب پیش‌نیاز سیستمی: ffmpeg
- ویندوز: از ffmpeg.org دانلود کن و به PATH اضافه کن.
- macOS: `brew install ffmpeg`
- لینوکس: `sudo apt install ffmpeg`

بدون ffmpeg، دوبله اصلاً کار نمی‌کند.

## ۲. نصب پکیج‌های پایتون
```bash
cd backend
pip install -r requirements.txt
```
این کار faster-whisper (تشخیص گفتار)، argostranslate (ترجمه آفلاین) و pyttsx3 (تبدیل متن به گفتار) را نصب می‌کند.
اولین اجرای faster-whisper مدل Whisper را (چند صد مگابایت) دانلود و کش می‌کند.

## ۳. نصب بسته‌های زبان Argos Translate
Argos برای هر جفت زبان مبدا→مقصد یک بسته جداگانه دارد. مثلاً برای ترجمه انگلیسی به فارسی:
```python
import argostranslate.package
argostranslate.package.update_package_index()
available = argostranslate.package.get_available_packages()
pkg = next(p for p in available if p.from_code == "en" and p.to_code == "fa")
argostranslate.package.install_from_path(pkg.download())
```
این اسکریپت را برای هر زبان مبدا/مقصدی که نیاز داری (مثلا en→fa، ar→fa) یک‌بار اجرا کن. بعد از نصب، ترجمه همان جفت زبان آفلاین کار می‌کند.

## ۴. اجرای Backend
```bash
cd backend
./run.sh
```
و آدرس IP همین کامپیوتر در شبکه محلی (مثلا `http://192.168.1.10:5000`) را در فیلد «آدرس Backend» داخل اپ Masten وارد کن.

## ۵. استفاده در اپ
دکمه «🎬 دوبله فیلم/سریال» را بزن، فایل ویدیو را انتخاب کن، زبان مقصد را انتخاب کن. اپ فایل را آپلود می‌کند،
وضعیت را هر چند ثانیه بررسی می‌کند، و در پایان ویدیوی دوبله‌شده را در مسیر داخلی اپ (`Android/data/com.masten.assistant/files/Masten_Dubbed/`) ذخیره می‌کند.

## محدودیت‌های واقعی این نسخه
- هماهنگی لب با صدا (lip-sync) انجام نمی‌شود؛ فقط طول هر جمله با کشیدن/فشردن صدا به زمان جمله اصلی نزدیک می‌شود.
- کیفیت صدا از TTS آفلاین سیستم می‌آید که طبیعی بودنش به‌پای صداپیشگی واقعی یا TTS ابری نمی‌رسد.
- فیلم‌های طولانی (بیش از ۲۰-۳۰ دقیقه) روی CPU معمولی می‌توانند خیلی طول بکشند؛ GPU سرعت تشخیص گفتار را به‌شدت بالا می‌برد.
- **کپی‌رایت**: این ابزار فقط تکنولوژی دوبله است. دوبله و/یا بازنشر فیلم و سریالی که مالک/دارنده مجوز آن نیستی، نقض قانون کپی‌رایت است. فقط برای محتوای شخصی یا دارای مجوز استفاده کن.
